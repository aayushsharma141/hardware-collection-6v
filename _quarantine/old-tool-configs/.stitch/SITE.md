# Hardware Collection (Jamshedpur)

Premium architectural hardware, door locks, modular kitchens, and digital security solutions.

## Brand Purpose
To provide luxury hardware solutions to architects, interior designers, and discerning homeowners. We focus on in-person showroom experiences supported by an editorial, high-end digital presence.

## Architecture
- **Tech**: Next.js 16 (App Router), React 19, Tailwind CSS v4.
- **Motion**: Desktop uses GSAP. Mobile relies on CSS transitions.
- **Conversion**: Primary CTA is WhatsApp consultation.
