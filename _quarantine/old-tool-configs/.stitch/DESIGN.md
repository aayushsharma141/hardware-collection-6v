# Hardware Collection - Stitch Design System

When generating UI for this project, you must adhere strictly to these rules to maintain the luxury, architectural "Digital Showroom" aesthetic.

## Visual Style
- **Aesthetic**: Cinematic, luxury hardware showroom, editorial, high-end architecture.
- **Theme**: Dark mode strictly. Very high contrast for images, subtle gradients for backgrounds.
- **Layout Approach**: Fluid spacing, large cinematic images, editorial typography. 

## Color Palette
Do not use standard web colors. Use only these hex codes or RGBA equivalents:

### Backgrounds & Surfaces
- **Cinema Black (Primary Background)**: `#090909`
- **Obsidian (Surface 1)**: `#11100f`
- **Graphite (Surface 2)**: `#181716`
- **Warm Black**: `#201d19`

### Accents & Typography
- **Brass (Primary Accent / Gold)**: `#c8a96e`
- **Deep Crimson (Highlight)**: `#8b1a4a`
- **Bone (Primary Text)**: `#e8e3d9`
- **Muted Bone (Secondary Text)**: `#aaa49a`

## Typography
- **Headings**: Serif fonts (Cormorant Garamond, Cinzel, or standard Georgia/Times New Roman if web-safe required). Use tracking/letter-spacing for an editorial feel.
- **Body & UI Text**: Sans-serif (DM Sans, Manrope, or standard system-ui). Keep UI text clean and legible.

## UI Components
- **Glass Panels**: For overlays or floating elements, use a dark glassmorphic effect: `background: rgba(17, 16, 15, 0.7); backdrop-filter: blur(12px); border: 1px solid rgba(200, 169, 110, 0.2);`
- **Buttons**: Minimalist. Often a simple thin border (Brass) or solid Brass background with Cinema Black text.
- **Images**: Treat images like art pieces. Use dramatic lighting, and ensure they have room to breathe.
