# Hardware Collection Mobile Homepage

Redesign the entire mobile homepage for a luxury architectural hardware showroom. The goal is to create a "purpose-built vertical showroom" that feels premium, editorial, and highly curated, not just a squashed desktop site.

## Key Features & Sections (in order):

1. **Hero Section (The Aperture)**
   - Minimalist header with a hamburger menu and brand wordmark.
   - Cinematic background image (dark, architectural).
   - Display typography (Cormorant Garamond) pushing against the edges.
   - A clear "Explore Collection" button.
   - *Requirement*: Must be highly legible on small mobile screens (320px width). Do not stack too many elements here.

2. **Category Discovery (The Gallery)**
   - A vertical list or horizontal scrolling carousel of product categories (Digital Locks, Door Handles, Modular Kitchens).
   - Use large image cards with generous padding (Spacing Scale 24).
   - Typography should overlap images or sit cleanly below them.

3. **Product Reel (The Signature)**
   - A curated selection of 3-4 signature hardware pieces.
   - Presented in a portrait orientation (editorial style).
   - Plenty of negative space around each piece.
   - Add to Cart / Inquiry buttons for each product.

4. **Material Journey (The Craft)**
   - A section highlighting the materials (Brass, Obsidian, Graphite).
   - Text-heavy but structured like a magazine article.
   - Use `display-sm` paired with `label-sm` for an "Art vs. Information" hierarchy.

5. **Consultation / Conversion (The Contact)**
   - A simplified consultation form or call-to-action block.
   - Category selection pills (e.g., "Architect", "Homeowner").
   - A prominent button to "Book Consultation" or "Chat on WhatsApp".
   - Stick to the bottom: A persistent mobile conversion bar with a WhatsApp icon/button.

## Visual Style:
- **Color Scheme**: Strict Dark Mode. Use Cinema Black (`#090909`) and Obsidian (`#11100f`) for backgrounds. Use Brass (`#c8a96e`) for subtle accents and Crimson (`#8b1a4a`) only for high-intent actions.
- **Design Aesthetic**: Organic Brutalism mixed with Architectural Luxury. No 1px solid borders. Use tonal shifts and negative space to separate sections.
- **Layout Approach**: Asymmetric, editorial. Let typography (Cormorant Garamond) act as a structural element. 
- **Typography**: Cormorant Garamond for display/headings, DM Sans for body.

## Platform:
Mobile web (375px width, responsive down to 320px).
