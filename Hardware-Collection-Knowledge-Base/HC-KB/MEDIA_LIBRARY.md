# 17 — Media Library Index
Asset inventory and naming convention — actual files live in cloud storage (Google Drive/Vercel assets), this is the index.

## Naming Convention
`hc-[category]-[brand]-[description]-[number].[ext]`
Example: `hc-kitchen-hafele-hero-01.jpg`

## Folders
- `/exterior` — storefront, signage
- `/interior` — showroom aisles, displays
- `/products` — by brand/category
- `/team` — owner + staff photos
- `/customer-purchases` — with consent only
- `/catalogs` — brand PDF catalogs (see Catalog Library)
- `/certificates` — authorized dealer certificates
- `/banners` — website/social hero graphics
- `/icons` — brand logos, category icons
