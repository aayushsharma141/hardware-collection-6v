## 1. What This Business Is

Hardware Collection is a premium architectural hardware showroom in Sakchi, Jamshedpur, owned by **Mukesh Khandelwal**. 20+ year history. Authorized dealer for **Hafele, Dorset, Labacha, Godrej, Hettich, Kich**.

It is a **retail/trader business**, not an e-commerce operation and not an enterprise chain. Every recommendation — content, systems, spend — must be sized to a single-showroom operation with a small team. Over-engineering is the default failure mode to guard against.

**Positioning statement:** Jamshedpur's authorized destination for premium door hardware, digital locks, and modular kitchen fittings — trusted expert, not a generic hardware wholesaler.

## 3. Website Purpose (do not deviate)

The website is a **lead-generation and trust engine** — it converts local search traffic into WhatsApp conversations, calls, and showroom visits. It is **not** an e-commerce checkout platform. No cart, no online payment, no SKU-level inventory on the frontend.

## 4. The Digital Funnel (governs all channel priority)

```
Instagram / Facebook  →  Google Search  →  Google Maps (GBP)  →  WhatsApp  →  Showroom Visit
```

Priority order for effort/spend: **GMB → WhatsApp Business → Website (minimal) → Instagram**. Do not front-load agency-grade social/paid-ads work before the GMB + WhatsApp foundation is solid.

## 6. Standing Rules for Anyone (or any AI) Working on This Project

1. **Proportionality first.** If a suggestion sounds like it's for a 50-person company, scale it down.
2. **WhatsApp number is always** 919835190738, pre-filled with a section-specific message — never a bare "contact us."
3. **Never propose e-commerce** unless Mukesh explicitly asks for it.
4. **Domain disambiguation:** there is an unrelated Kolkata-based "Hardware Collection" — never link or reference it; always clarify Jamshedpur/Sakchi in copy.
5. **Brand names must stay accurate**: Hafele, Dorset, Labacha, Godrej, Hettich, Kich — do not add or imply brands not actually stocked without confirming with Mukesh.
6. **Agent vs. owner tasks**: every SOP/task list must mark which steps Aayush (or an assistant) can execute directly vs. which need Mukesh's sign-off (pricing, vendor terms, financial commitments).
7. **Placeholders are labeled, not invented.** Where a document needs real data only Mukesh has (vendor terms, actual FAQs from real customers, true margins), it is marked `[NEEDS INPUT — Mukesh]` rather than filled with plausible-sounding fiction.
