## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Visitor keystrokes -> search matching | The only genuinely user-controlled input this phase adds to the landing page |
| Sanity settings -> WhatsApp href | `settings.whatsappNumber` flows into an outbound `wa.me` link |
| Editor content -> rendered results | Category, product and brand names rendered into result rows |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-------------------|
| T-9-01 | Tampering | Search input | mitigate | Matching is client-side `Array.filter` over already-fetched props. Search text never concatenates into a GROQ string and never reaches `client.fetch`. Enforced by this plan's grep gate returning zero matches for `groq`/`client.fetch` |
| T-9-12-01 | Spoofing / Tampering | Outbound WhatsApp link construction | mitigate | The href is produced by `@/lib/whatsapp` from `settings.whatsappNumber` or the hardcoded fallback — never from user input, so there is no attacker-controlled redirect target. Enforced by the grep gate barring a literal `wa.me` string in this file |
| T-9-12-02 | Information Disclosure | Overstated business claims in the stat row | mitigate | Counts are computed from published documents, zero segments are omitted, and the years claim is gated behind an explicit confirmation flag defaulting to false |
| T-9-02 | Tampering | GROQ slug parameterization | not applicable | This plan issues no queries |
| T-9-SC | Tampering | npm installs | not applicable | No new packages — `lucide-react` and `motion/react` are already installed |

</threat_model>
