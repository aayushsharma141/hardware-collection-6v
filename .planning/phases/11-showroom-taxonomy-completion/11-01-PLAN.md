<objective>
Unblock Phase 11 development and visual staging by establishing an automated DOM-based web scraping and staging pipeline. Collect high-fidelity temporary reference imagery and metadata from authorized partner websites and architectural references to populate the 35 newly seeded showroom categories, without violating the project's locked rules against fake e-commerce data.
</objective>

<context>
Phase 11 expanded the showroom taxonomy to 48 categories across 5 families, but 35 categories (including all 11 Handles & Knobs styles) lack hero images. Sanity currently holds only 6 generic renders. Real showroom photography by Mukesh is a pending business dependency. This plan implements a temporary staging asset pipeline using DOM extraction so UI testing, card grids, responsive carousels, and visual audits can proceed in staging environments.
</context>

<tasks>
1. **Target Mapping & DOM Query Strategy**:
   - Map each of the 35 categories to authoritative partner sources:
     - Handles & Knobs (11 styles): Furnipart, Dorset, Hafele, Maranello
     - Furniture Hardware (9 categories): Blum, Hettich, Hafele
     - Bathroom (8 categories): Decor Bath, Labacha, Ozone
     - Door Hardware (4 categories): Dorset, Yale, Geze
     - Kitchen & Wardrobes (3 categories): Blum, Hettich
   - Define DOM selector rules for querying high-res `<img>` tags (`srcset`, `data-src`, `data-zoom-image`).

2. **DOM Scraping Tool (`scripts/scrape/extract-web-assets.ts`)**:
   - Use Playwright (`@playwright/test` / `playwright`) to navigate to target catalogue pages.
   - Evaluate DOM nodes (`document.querySelectorAll('img')`) to extract image URLs, alt descriptions, and dimensions.
   - Download assets into local staging directory: `public/staging/temp-taxonomy/[category-slug]/`.

3. **Asset Normalization (`scripts/scrape/normalize-assets.ts`)**:
   - Process downloaded assets to match the canonical 1376x768 (16:9) aspect ratio.
   - Convert to optimized WebP format with pinned dimensions to respect CLS budget (<= 0.10).

4. **Staging Sanity Seeder (`scripts/cms/seed-staging-hero-images.ts`)**:
   - Upload normalized assets to Sanity with explicit metadata: `{ isTemporary: true, stagingSource: "web-dom-extract" }`.
   - Update `heroImage` on the 35 categories without overwriting existing authentic assets.

5. **Rollback & Verification (`scripts/cms/purge-staging-assets.ts`)**:
   - Implement teardown script that identifies and removes all `isTemporary: true` assets from Sanity when owner photography arrives.
   - Run `npx tsx scripts/release-verification.ts` to ensure build, type safety, and linting remain pristine.
</tasks>
