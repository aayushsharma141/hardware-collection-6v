# VISUAL DNA — Hardware Collection Asset Production

*Every generated or AI-edited asset must conform to this contract before being promoted to `/public/cinema/`. This document is the single source of truth for the photographic campaign language.*

---

## Camera Language

```
35–50mm editorial architecture perspective
macro shots: 85–100mm equivalent
minimal lens distortion
no fisheye
no extreme wide-angle
```

## Lighting

```
Single dominant directional key light
Soft controlled fill (never flat)
Narrow specular highlights on metal edges
Warm reflected accent (brass-temperature: ~3000K)
Deep retained shadow — blacks are not crushed to pure black
```

## Environment

```
Obsidian / graphite / charcoal architectural surfaces
Minimal, unidentifiable surfaces
No distinguishable room, countertop, or furniture
No recognizable interior style
```

## Metal Rendering

```
Physically plausible reflections
Visible surface grain (brushed / machined / satin)
Correct edge highlight geometry
Specular width appropriate to finish (brushed = linear, satin = wide, PVD = narrow)
No liquid chrome
No plastic-looking specular
No mirror-ball reflections
```

## Color Palette

```
Black         #0a0a0a – #141414
Graphite      #1c1c1c – #2a2a2a
Steel         #6e7278 – #9ca3af
Muted Brass   #b59a6a – #d4b483
Warm Neutral  #e5e0d8

No: cyan, blue, purple, neon, pure white backgrounds, pure red
```

## Contrast

```
Deep blacks — retained
Controlled highlights — not blown
Product detail always visible in shadow areas
No HDR halo
```

## Composition

```
Large negative space (minimum 40% of frame)
Asymmetric placement — hardware is never centered unless intentional
Editorial framing — not ecommerce product-on-white
Subject breathing room
Typography-safe zones on left or right thirds
```

## Camera Motion Language (for video/Veo)

```
Slow / heavy / deliberate
Architectural — not commercial product-ad movement
Imperceptible dolly preferred over visible pan
Light passes across hardware, not camera orbiting hardware
```

---

## Asset Source Classification

Every asset in `ASSET_MANIFEST.md` must be tagged:

| Tag | Meaning |
|-----|---------|
| `AI-GENERATED` | Fully synthesized by image engine |
| `AI-EDITED-REAL` | Real photography processed/enhanced by AI |
| `REAL-PHOTOGRAPHY` | Authentic client or product photography, no AI |
| `BRAND-ASSET` | Official brand logo/asset, unmodified |
| `VIDEO-GENERATED` | AI video (Veo or equivalent) |

---

## Absolute Prohibitions

```
✕ Random luxury interiors
✕ Generic marble countertops
✕ Generic hotel bathrooms
✕ Floating products with no surface contact or shadow
✕ Excessive gold
✕ Neon lighting of any colour
✕ Futuristic / cyberpunk UI elements
✕ People holding or touching products
✕ Fake logos or invented brand marks
✕ Invented text or signage in frame
✕ Fake showroom signage
✕ Mechanically impossible hinges or handles
✕ Impossible handle geometry
✕ Melted or liquefied metal appearance
✕ Plastic-looking chrome
✕ Excessive depth-of-field blur obscuring subject
✕ Stock-photo composition (product on white, fake wood floor)
✕ Generic AI luxury showroom aesthetic
✕ "Dreamy" soft-focus mood lighting
```
