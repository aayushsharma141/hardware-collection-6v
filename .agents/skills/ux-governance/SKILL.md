# UX & Flow Governance Skill

## Principles
1. **Focal Point Discipline:** Every view must present exactly ONE primary visual focal point.
2. **State Complete:** Every flow must handle Loading (`PageSkeleton`), Empty ("Room under curation"), Error (`ErrorBoundary`), and Success states seamlessly.
3. **Friction Minimization:** Eliminate unnecessary form fields or redundant navigation steps in lead capture funnels.
