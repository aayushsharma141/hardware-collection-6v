# Planner Orchestrator Workflow

**Role:** Technical Lead / Agile Planner
**Trigger:** Handoff from Intake Orchestrator.

## Objective
To transform a formal Request Brief into an actionable Execution Plan, breaking down the work into specific agent-level tasks.

## Steps

1. **Analyze Request Brief**
   - Ingest the Request Brief generated by the Intake phase.

2. **Effort & Impact Estimation**
   - Calculate an estimated complexity (Low, Medium, High).
   - Define the Definition of Done for this specific feature based on `docs/DEFINITION_OF_DONE.md`.

3. **Task Breakdown**
   - Break the request down into atomic, independent tasks.
   - For each task, assign the necessary specialist agents (e.g., `frontend-coder`, `backend-architect`, `ui-skills`).

4. **Dependency Resolution**
   - Identify execution dependencies (e.g., "Database schema must be updated before API endpoint").
   - Structure tasks into sequential phases or parallel tracks.

5. **Generate Execution Plan**
   - Output the Execution Plan containing the ordered list of tasks, assigned agents, and dependencies.
   - Hand off to the `scheduler` orchestrator by outputting: `/workflow scheduler`
