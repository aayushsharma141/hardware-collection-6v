# Decision Engine Orchestrator Workflow

**Role:** Chief Product Officer & Portfolio Committee
**Trigger:** Handoff from `mission-planner.md` after `MissionBrief.md` is generated.

## Objective
To decide whether a proposed mission should proceed to execution planning. Evaluates business value, expected revenue, development cost, risk, and policy trade-offs.

## Decision Steps

1. **Ingest Mission Brief**
   - Read `MissionBrief.md` generated by the Mission Planner.

2. **Economic Pre-Audit (Product Economist)**
   - Query `.agents/intelligence/product-economist.yml`.
   - Calculate projected ROI:
     $$\text{ROI} = \frac{\text{Expected Revenue} + \text{User Value} - (\text{Dev Cost} + \text{Maintenance Drag} + \text{Risk Cost})}{\text{Dev Cost}}$$
   - If ROI < 1.2, **REJECT MISSION** and emit `MissionRejected` event with economic rationale.

3. **Organizational Memory Check**
   - Query `.agents/memory/organizational-memory.yml`.
   - Ensure this exact idea or approach was not previously attempted and rejected (e.g. past failed experiment, negative customer interview feedback).

4. **Policy & Resource Conflict Resolution**
   - Resolve competing priorities across multiple active missions.
   - Allocate resource budget from `.agents/runtime/resource-manager.yml`.

5. **Decision Verdict & Handoff**
   - Output `DecisionVerdict.md` using one of the following 6 verdicts:

   | Verdict | Meaning |
   |:---|:---|
   | `APPROVED` | Feature passes all economic and strategic checks. Proceed immediately. |
   | `APPROVED_WITH_CONDITIONS` | Feature approved but must satisfy named conditions (e.g. "only if performance budget is preserved"). |
   | `DEFER` | Feature has merit but timing is wrong. Re-evaluate in next sprint cycle. |
   | `MERGE_INTO_INITIATIVE` | Feature is a duplicate or subset of an existing approved initiative. Fold into it. |
   | `REQUIRES_EXECUTIVE_REVIEW` | Strategic value is high but cost or risk exceeds autonomous approval threshold. Flag for human decision. |
   | `REJECTED` | Feature fails economic analysis with no strategic exception pathway. |

   - Include `confidence_score` (0.00–1.00) on the verdict to indicate how certain the Decision Engine is.
   - If `APPROVED` or `APPROVED_WITH_CONDITIONS`, hand off to `execution-planner.md`: `/workflow execution-planner`
