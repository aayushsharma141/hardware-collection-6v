## 2. Architecture & Design Review

### A. Problem Addressed
Previously, subcategory galleries on `/collections` embedded product specimen thumbnails, brand logos, and multi-line page references inline directly within 4-column desktop and 2-column mobile cards. This produced bloated ~800px cards, awkward logo wrapping (e.g. Häfele dominating while Maranello and Tattva were squashed), and uneven vertical alignment.

### B. Architectural Pattern
- **Modal Component (`CategoryDetailModal.tsx`)**:
  - Encapsulates rich category specification in a centered 2-column architectural dialog (`Dialog`).
  - **Left Column**: Visual category photography, family breadcrumb (`DOOR HARDWARE · SPECIFICATION`), large serif title, editorial blurb, and dedicated WhatsApp Showroom Guidance CTA.
  - **Right Column**:
    - **Authorized Brand Catalogues**: Normalized brand logos (`ModalBrandMark` with constant visual area calculation), brand title, best-matching page reference (`Page 25 · 12 pages in official catalogue`), and direct `Open Catalogue →` deep-link to the PDF viewer at `/catalogues`.
    - **Showroom Display Products**: Thumbnail cards with product title, brand tag, and click-to-open drawer trigger.
    - **Cross-Link Bridge**: Direct link to `/catalogues` for complete manufacturer directory access.
- **Streamlined Gallery Tiles (`CollectionExplorer.tsx`)**:
  - Restores gallery cards to clean ~360px uniform tiles.
  - Shows category photo, sequence numeral (`01`), serif title, 2-line clamp blurb, and subtle count teaser pills (`[5 Brands]`, `[1 Product]`).
  - Action footer provides primary **`Explore Range →`** button (modal trigger) and direct **`Enquire`** link.
- **Locked Architectural Constraints Compliance (`AGENTS.md`)**:
  - Verified that `/collections/<slug>` is NEVER created as a route and never linked.
  - Both `CategoryDetailModal.tsx` and `CollectionExplorer.tsx` pass architectural guard tests preventing sub-route generation.

## 3. Security, Performance & Code Quality Review

- **Zero Secrets / Leaks**: No API tokens, keys, or credentials exposed in frontend components.
- **Safe Outbound Links**: All external WhatsApp links use `target="_blank"` and `rel="noopener noreferrer"`.
- **Image Performance**: Utilizes `LazyImage` / Next.js Image with WebP format, LQIP blur placeholders, and responsive `sizes` definitions preventing Cumulative Layout Shift (CLS).
- **Bundle Optimization**: Clean imports; unused SVG icons removed; no dead code introduced.

---

## 4. Accessibility & Touch Interaction (WCAG AA)

- **Radix Dialog Primitives**: Built on accessible Radix primitives with semantic `DialogTitle` and `DialogDescription`.
- **Keyboard Navigation**:
  - Tab order strictly follows visual layout (Title → WhatsApp CTA → Brand Catalogues → Showroom Products → Close).
  - Pressing `Escape` cleanly dismisses the modal and restores focus to the invoking trigger button.
- **Touch Target Compliance**:
  - All interactive elements meet the minimum 44×44px touch target requirement (`min-h-11`).
  - Enhanced dialog close button (`DialogPrimitive.Close`) with floating circular styling (`bg-[var(--surface)]/90 backdrop-blur-xs border border-[var(--border)] rounded-full shadow-xs`), ensuring clear visibility and effortless tapping over light or dark imagery.
- **Accessible Labelling**: Screen reader announcements provided on all card triggers (`aria-label={`View ${category.name} specification and brand catalogues`}`).
