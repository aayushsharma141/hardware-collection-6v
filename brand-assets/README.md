# Hardware Collection Brand Assets

This directory contains the Brand Asset Library for Hardware Collection's 21
currently authorized brands. Most assets are still outstanding and must be
supplied by each brand representative — see `BRAND_REP_REQUEST_PACK.md`.

Each brand directory contains subdirectories for `logos`, `hero` imagery,
`product-families`, `products`, and `references`.

## Guidelines
- Do not duplicate assets that already exist.
- Cover only the 21 authorized brands listed above (Kich is no longer authorized).
- Store official catalogues as referenced in `BRAND_ASSET_MANIFEST.md`.
- No AI-generated or generic stock photography allowed.
- Follow naming conventions: `hc-[category]-[brand]-[description]-[number].[ext]`.
- Assets scraped from the web or Wikimedia are REFERENCE_ONLY and must not ship to
  production until the brand supplies an approved version.
